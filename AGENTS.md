## Ringkasan Cepat Aturan Wajib

1. **Perintah Build & Test (Wajib di PowerShell):**
   - `cargo` berada di `$env:USERPROFILE\.cargo\bin`.
   - Toolchain menggunakan `stable-x86_64-pc-windows-gnu` dan `target-dir` berada di `D:/Rust/.nexora-target` (lihat [`.cargo/config.toml`](file:///d:/Rust/Nexora%20Studio/.cargo/config.toml)).
   - Selalu hentikan proses `nexora-studio` sebelum kompilasi agar tidak terkena *file lock*:
     ```powershell
     $env:PATH = "$env:USERPROFILE\.cargo\bin;$env:PATH"
     Get-Process nexora-studio -ErrorAction SilentlyContinue | Stop-Process -Force
     cargo test
     cargo build
     ```
   - Lokasi binary: `D:\Rust\.nexora-target\debug\nexora-studio.exe`.
   - **Backend Renderer Dikunci ke Vulkan / DirectX 12 — OpenGL Dilarang:** [`src/main.rs`](file:///d:/Rust/Nexora%20Studio/src/main.rs) menyetel `renderer: eframe::Renderer::Wgpu`, `instance_descriptor.backends = VULKAN | DX12`, serta `power_preference = HighPerformance`. Fitur `glow` sengaja **tidak** dipakai di `Cargo.toml`, dan crate `wgpu` dideklarasikan langsung (`features = ["dx12"]`) agar backend DirectX 12 ikut terkompilasi sebagai cadangan Vulkan.
   - Alasan larangan OpenGL: jalur OpenGL (backend `gles` milik `wgpu` maupun `glow`) selalu bermuara ke driver OpenGL Intel (`igxelpicd64.dll`, build 32.0.101.5972), yang melaporkan **Access Violation `0xc0000005`** ke Windows Event Log dan mematikan seluruh proses tanpa dialog ketika **Program Projector** meminta window/surface kedua. Jangan pernah mengembalikan `Backends::GL` atau fitur `glow` selama projector masih membuat window terpisah.

   - **Tipografi Keseluruhan UI (Rubik Offline):** Seluruh teks antarmuka aplikasi menggunakan font **Rubik** (lisensi SIL OFL) yang di-*embed* offline dengan ketebalan ramping dan proporsional:

     - `Rubik-Regular` (weight 400): Judul modal dialog (`TextStyle::Heading`), header section, badge status siaran (`LIVE`, `REC`).

Drop dihitung dari *slot* yang tidak menyertakan item yang diseret (drop ke slot sendiri = no-op), lalu dieksekusi oleh `Scene::move_source_to_slot()`. Perubahan Z-order hanya menyentuh Preview; Program mengikuti lewat `sync_if_linked()` (isolasi Program tetap dijaga sebelum `TRANSITION ->`).

Berlaku di **kedua mode tampilan**: `List` (indikator garis horizontal antar baris) dan `Grid` (indikator garis vertikal di celah antar kartu, slot dihitung urutan baca: kartu di baris yang sama di kiri pointer + semua kartu di atasnya). Urutan strip murni tampilan: `preview_scene_id` / `program_scene_id` mengikuti **id**, jadi reorder tidak boleh mengubah scene mana yang LIVE/Preview dan tidak memerlukan `sync_if_linked()`.

   - **Audio Filters (Gain, Noise Gate, Noise Suppression) per Source Audio:**
     - Filter audio hanya menempel pada 3 jenis source audio capture (`Audio Input Capture`, `Audio Output Capture`, `Application Audio Capture`) melalui `SourceItem::audio_filters` (`Vec<AudioFilter>`, urut dan berpengaruh). Bus global (`Mic / Aux`, `Desktop Audio`) **tetap mentah / tanpa filter** persis OBS, supaya endpoint yang sama tidak diproses dua kali.

Setiap entri bisa di-bypass (`AudioFilter::enabled`) dan bisa diurutkan naik/turun.

Ini mencegah *double-gating*. Konsekuensinya mic yang baru ditambahkan terekam **mentah** sampai preset ini dipasang.

4. **Geometri Frame Decoder Media Foundation (Padding 1088 & Row Pitch):**
   - Decoder membulatkan 1920x1080 ke permukaan **1920x1088** (kelipatan makroblok) dan mengisi baris sisa dengan **nol**. Sampel NV12 yang semuanya nol **bukan hitam**: luma 0 + chroma 0 dikonversi menjadi **`(0, 154, 0)`**, sehingga blit baris padding menghasilkan **garis hijau** di bawah setiap video. Jadi jangan pernah memakai `MF_MT_FRAME_SIZE` mentah sebagai tinggi gambar.
   - Ukuran gambar yang terlihat diambil dari *display aperture* (`MF_MT_GEOMETRIC_APERTURE` → `MF_MT_MINIMUM_DISPLAY_APERTURE` → `MF_MT_PAN_SCAN_APERTURE`) melalui `win32_capture::read_frame_geometry`, lalu disimpan sebagai `FrameCrop` pada `MfMediaFileSession`; konversi (`nv12_to_rgba_scaled`, `yuy2_to_rgba_scaled`, jalur RGBA32) **wajib** memakai `crop` tersebut.
   - Lebar baris permukaan decoder bisa lebih besar dari lebar gambar (`MF_MT_DEFAULT_STRIDE`); indeks piksel harus memakai `pitch` (stride), bukan `width`, agar baris tidak terbaca miring dari area padding.
   - Kedua perilaku ini dijaga *unit test* `nv12_padding_rows_are_cropped_away` dan `nv12_honours_padded_row_pitch` di [`src/capture/mod.rs`](file:///d:/Rust/Nexora%20Studio/src/capture/mod.rs). Jangan menghapusnya saat refactor.
